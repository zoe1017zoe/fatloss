# 減脂追蹤教練

拍照記錄熱量、追蹤蛋白質與步數的個人減脂 APP（PWA）。所有紀錄存在使用者手機，AI 使用 Google Gemini 免費方案。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | APP 主程式 |
| `manifest.webmanifest` | 加入主畫面的名稱與圖示設定 |
| `sw.js` | 離線快取 |
| `icons/` | APP 圖示 |

## 一、上傳到 GitHub Pages

1. 登入 GitHub，右上角「＋」→「New repository」。
2. Repository name 輸入 `fatloss`（可自訂），選 **Public**，按「Create repository」。
3. 在新倉庫頁面點「uploading an existing file」，把本資料夾內**所有檔案與 icons 資料夾**拖進去，按「Commit changes」。
4. 進入倉庫「Settings」→ 左側「Pages」→ Source 選「Deploy from a branch」，Branch 選 `main`、資料夾 `/ (root)`，按「Save」。
5. 等 1–2 分鐘，頁面上方會出現網址，格式為 `https://你的帳號.github.io/fatloss/`。

## 二、在 iPhone 加入主畫面

1. 用 **Safari** 開啟上述網址（其他瀏覽器無法加入主畫面）。
2. 點下方「分享」按鈕 →「加入主畫面」→「新增」。
3. 之後一律從主畫面圖示開啟。直接用 Safari 分頁開啟時，iOS 可能在長期未使用後清除資料。

## 三、申請 Gemini API 金鑰

1. 用 Google 帳號開啟 https://aistudio.google.com/apikey
2. 按「Create API key」，複製產生的金鑰（`AIza` 開頭）。
3. 開啟 APP →「設定」→ 貼上金鑰 → 按「測試金鑰」。
4. 若出現「找不到指定模型」，按「取得可用模型」後從模型欄位重新選擇 Flash 系列模型。

注意：
- 金鑰只存在使用者手機，不在程式碼內，倉庫公開也不會外洩。
- 免費方案的內容（含照片）可能被 Google 用於改善模型。
- 免費額度依 Google 公告調整，用完會顯示提示，隔天恢復。

## 四、使用方式

下方輸入框可直接用自然語言：

| 輸入範例 | 處理方式 |
|---|---|
| 拍照或選照片（可加文字「飯只吃半碗」） | AI 拆解餐點 → 確認或修改數值 → 儲存 |
| 「中午吃了一個排骨便當加無糖豆漿」 | AI 拆解餐點 |
| 「今天走了 9500 步」 | APP 直接記錄，不使用 AI 額度 |
| 「早上 82.6 公斤」 | APP 直接記錄體重，不使用 AI 額度 |
| 「練了胸背一小時」 | AI 記錄運動並點評 |
| 「今天還能吃什麼？」 | AI 依當日紀錄回答 |
| 星號按鈕 | 從常用食品快速新增，不使用 AI 額度 |

- 輸入框上方的「早餐／午餐／晚餐／點心」決定這筆餐點的餐別，會依時間自動預選。
- 熱量累計、剩餘額度、步數由 APP 計算；運動消耗只記錄，不加回可攝取額度。
- 「食品庫」可手動新增或拍營養標示新增常用食品（例如桂格大燕麥片）。
- 「紀錄」可點任一天查看或補記；「趨勢」顯示熱量、蛋白質與體重變化。

### 首次設定精靈

第一次開啟時引導填寫性別、年齡、身高、體重、生活型態、運動習慣、走路量、目標與體態描述，自動算出每日熱量、蛋白質、步數與重訓計畫。預設值為第一位學員的資料，直接按「下一步」即可得到原提示詞的數值。之後可在「設定」→「重新執行設定精靈」重來。

### 每 14 天自動調整

距上次調整滿 14 天、且近兩週有 10 天以上飲食紀錄時，今日頁會出現「教練兩週調整建議」卡，按「套用建議」即更新所有目標。

| 規則 | 內容 |
|---|---|
| 減脂速度 | 每週下降 0.5–1% 體重為理想；超過 1% 提高熱量；偏慢或停滯則下修 |
| 單次調幅 | 目標熱量每次最多 ±150 大卡 |
| 安全底線 | 目標下限不得低於依最新體重重算的基礎代謝 |
| 吃超過目標 | 平均攝取高於目標上限時不下修，請先回到目前目標 |
| 步數計畫 | 達標率 70% 以上時提高 1,000–2,000 步，最高 10,000 步 |
| 重訓計畫 | 穩定達成且步數已達 10,000 時增加，最高每週 3 次 |

調整需要體重趨勢，請每週至少量一次體重；超過 7 天未記錄時今日頁會提醒。

## 五、更新 APP

修改檔案後重新上傳到同一個倉庫即可。若手機仍顯示舊版，將 `sw.js` 第 2 行的版本號（如 `fatloss-v2`）加 1 再上傳，關閉 APP 後重新開啟兩次。

## 六、資料結構（IndexedDB，Dexie.js）

| 資料表 | 內容 |
|---|---|
| `kv` | 設定（金鑰、個人資料、目標） |
| `foods` | 常用食品（每份熱量與三大營養素、使用次數） |
| `meals` | 餐點（日期、餐別、品項清單、照片編號、教練點評） |
| `photos` | 壓縮後的餐點照片 |
| `activities` | 運動與步數 |
| `bodyLogs` | 體重 |
| `chats` | 提問與教練回覆 |
